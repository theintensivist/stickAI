Install stickAI in your browser

No software to install. You need Chrome or Edge on a computer (Firefox and Chrome on Android also work), a USB-C cable that carries data, and an M5Stack StickS3.

  1. Connect the StickS3 to the computer with the USB-C cable.
  2. Click Install stickAI below, choose the stick's port (often called USB JTAG/serial debug unit) and click Connect.
  3. Click Install. On the first install, tick Erase device for a clean start. When updating later, leave it unticked to keep your Wi-Fi, API key, timers and reminders.
  4. Wait about a minute until it says the installation is complete, then press the stick's power button once to restart it.
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. iPhone and iPad can't install firmware. The installer only works when this page is opened over https. Version 0.11 · ESP32-S3

If the stick isn't found

  1. Try another USB-C cable. Some cables only charge.
  2. Put the stick in download mode: hold the power button until the green light blinks, then let go. Then click Install stickAI again.
  3. On Windows, close any other program that might be using the port, such as a serial monitor.

After installing

  1. Get a free Gemini API key at aistudio.google.com/apikey. Don't add billing to that project, so it can never cost you money.
  2. The stick shows a QR code. Scan it with your phone to join the stickAI-Setup Wi-Fi (the password is on the stick).
  3. On the page that opens, enter your Wi-Fi and paste the API key, then tap Save and restart.
  4. Hold A and say "Hello, can you hear me?"

Your API key is typed on that page and stored only on your stick. It is never part of this download.
